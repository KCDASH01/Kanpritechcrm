# CRM frontend dependency remediation

Next.js 15.5.29 is the smallest supported major upgrade from 14.2.4 that includes both image optimizer fixes and the subsequent self-hosting response isolation fix. Next.js 15 receives maintenance security updates through January 31, 2027. Plan a separate upgrade to the active LTS line before that date. [AVIF advisory](https://github.com/advisories/GHSA-2xp9-vwfh-vxw4) · [SVG advisory](https://github.com/advisories/GHSA-2464-fhr4-w9xw) · [Response isolation advisory](https://github.com/advisories/GHSA-pc58-hwjq-p385) · [Next.js support policy](https://nextjs.org/support-policy)

## Compatibility

- The CRM uses the App Router. React, React DOM, and the Recharts `react-is` peer are locked to 19.3.1. React 19 requires an explicit initial value for three refs in the Assistant and Target Coach. They still start as `undefined`. Next's TypeScript setup adds the ES2017 target and a generated route declaration reference. [Next.js upgrade guide](https://nextjs.org/docs/app/guides/upgrading/version-15) · [Recharts installation notes](https://github.com/recharts/recharts/tree/v3.8.1#installation)
- The app's Node engine range accounts for both the native image library and development-tool requirements. For a Linux release build, use a currently supported, patched Node 22 or 24 LTS release that satisfies `package.json`. Install optional dependencies so Next.js can load the platform's native Sharp and libvips packages. [Node.js release schedule](https://nodejs.org/en/about/previous-releases)
- The PostCSS override replaces Next.js's exact 8.4.31 dependency with the same patched 8.5.33 version used by the app's CSS tooling. The Sharp override enforces the vendor's fixed 0.35.5 floor even if the lockfile is regenerated.

## Reachability and verification

- The installed production npm audit went from one critical, six high, and two moderate affected packages to zero. Direct fixes upgraded Next.js and Axios. The lockfile also patched DOMPurify, fflate, follow-redirects, form-data, Nano ID, PostCSS, and source-map-js. The separately audited billing PDF renderer reported zero production npm findings.
- The self-hosted Next.js configuration serves the image optimizer for the built-in CRM logos. The AVIF advisory affects processing in Sharp's upstream decoder. The SVG advisory applies to an upstream image library on glibc-based Linux. The original frontend lockfile had no Sharp dependency, so historical exposure depends on the image stack installed with the deployed app. The updated Next.js release checks for libheif 1.23.2 or newer before optimizing AVIF. The Windows test runtime loaded Sharp 0.35.5 with libheif 1.23.5. The lockfile includes the Linux native packages. The production host and any proxy rules were outside this local review.
- The source tree has no Next.js middleware or custom `next start` wrapper, so the middleware-specific authorization advisory does not map to the reviewed CRM entry points. Authentication and permissions are enforced by the Laravel API. Axios API calls are initiated by browser components and the Next.js release route returns static metadata. Node-only Axios redirect, proxy, and HTTP/2 findings have no identified server request path here. PostCSS consumes repository CSS during the build. These dependencies were patched even where the affected feature was absent from the reviewed application.
- Run `npm audit --omit=dev` against the installed frontend tree after any lockfile changes. Before a separately approved release, repeat the production build and benign logo optimizer check on the deployment's Linux architecture and verify the loaded Sharp version is at least 0.35.5.

## Local tests

Node 24.14.0 and npm 11.10.0 completed standalone TypeScript checking and the Next.js production build. The existing Lead Management, Assistant, and Subscription Status frontend tests passed. The Laravel suite used in-memory SQLite and passed 115 tests with 1,085 assertions. It skipped seven opt-in import benchmarks and two disposable MySQL fixtures.

Headless Edge ran against the production build with a synthetic loopback API. It verified anonymous redirects, failed and successful login, logout, Owner/Admin/Employee controls, dashboard and conversion metrics, billing and draft document actions, reports and targets, lead integrations, the Assistant and notifications, Future Lead, and the mobile CSV import through confirmation and completion. An expired Business membership was denied import access. The release endpoint kept its `no-store` header, and the image optimizer converted the bundled PNG logo to WebP.
